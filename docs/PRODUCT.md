# Product Structure

## Human Sensing System

This system is responsible for collecting user behaviour and emotion.

### Functions

| Sub-function         | Collected Content                      | Type            |
| -------------------- | -------------------------------------- | --------------- |
| Activity Monitoring  | Active / Idle / Continuous Usage       | Behaviour       |
| Passive Mood Checkin | TBD                                    | Affective State |
| Active Mood Checkin  | Character Actively Ask for Mood Check  | Affective State |
| Daily Routine        | Active Time, Rest Time, Usage Patterns | Behaviour       |

## Companion Feedback System

This is the foundation of the entire project. Users must first see a truly interactive pixel-based creature, rather than a standard GUI window.

### Functions

- [ ] Character Rendering: Display Pixel Character, Transparent Background
- [ ] Idle Animation: Breath, Blink, Standing, and other basic animations
- [ ] Movement: Movement such as Walking, Jumping, Teleportation
- [ ] Mouse Interaction: Click, Drag, Touch, eyes follow
- [ ] Facial Expressions: Happy, Sad, Sleepy, Surprised
- [ ] Character States: Idle, Walking, Sleeping, Interacting (should be interruptible)
- [ ] Personality: Character should display some basic simulated characteristic
- [ ] Customization: Change Color, Apparence, Character, etc...
